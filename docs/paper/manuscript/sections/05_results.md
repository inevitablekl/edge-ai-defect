# 4 结果与分析

## 4.1 正确性验证结果

在比较不同数据路径的性能之前，首先验证 CUDA 预处理路径是否保持既有检测任务语义。V2R 以相同的 180 幅测试图像和 V0 任务级结果为基准进行正确性评价，结果如表2所示。

**表2　V0与V2R任务级正确性验证结果**

| 指标 | V0 | V2R | 绝对差异 | 允许差异 | 结果 |
|---|---:|---:|---:|---:|---|
| Precision | 0.6913 | 0.6913 | 0 | 0.010 | 通过 |
| Recall | 0.6991 | 0.6991 | 0 | 0.010 | 通过 |
| mAP50 | 0.6476 | 0.6476 | 0 | 0.005 | 通过 |
| mAP50-95 | 0.3523 | 0.3523 | 0 | 0.005 | 通过 |

除表2中的总体指标外，类别级最大 AP50 和 recall 绝对差异也均为0，分别低于预设的0.020和0.030阈值。由此可见，在当前180幅测试图像及冻结检测配置下，V2R 的任务级检测结果满足预先设定的正确性判据。这里的结论仅针对任务级评价，不扩展为原始推理张量的逐元素或比特级等价。

V3R 不进行第二次独立的任务级正确性验收，而是在 V2R 已确定的 CUDA 预处理语义基础上验证伴随路径的一致性。180幅图像的帧顺序、路径和几何信息均通过检查，运行过程中无丢帧，能够正常完成流结束和资源回收；预处理张量摘要和检测结果摘要均与 V2R 一致，检测数量均为447。因此，V3R 的验证结果支持其作为仅改变主机暂存内存类型的伴随路径参与后续性能比较，但不将该身份验证解释为独立任务级正确性评价。

## 4.2 CUDA预处理的主要性能收益

图2给出了 V0、V2R 和 V3R 在统一运行协议下的平均帧率，其中误差棒表示每种路径5次独立运行 FPS 的样本标准差。V0 的平均帧率为54.600 FPS，样本标准差为0.223 FPS；采用 pageable 主机暂存和 CUDA 预处理的 V2R 达到122.122 FPS，样本标准差为0.492 FPS。V2R 相对于 V0 的帧率比为2.236671×，即 FPS 提高123.6671%。

**图2　V0、V2R和V3R平均帧率比较**

逐帧延迟结果如图3所示。V0 的平均延迟、P95和P99分别为18.273、18.854和19.068 ms；V2R 分别降低至8.140、9.827和11.529 ms。按照冻结的成对比较结果，V2R 相对于 V0 的平均延迟降低55.4519%，P95和P99分别降低47.8780%和39.5385%。

**图3　V0、V2R和V3R平均及尾延迟比较**

结合帧率和延迟两组结果，在固定模型、INT8 Engine、测试数据和统一计时合同下，从 V0 的 CPU/OpenCV 预处理路径切换到 V2R 的 pageable 主机暂存与 CUDA 预处理路径后，平均帧率提高，同时平均及尾部延迟降低。因此，本文的主要观测性能收益集中在这一受控数据路径变化中。需要强调的是，V0→V2R 同时改变了主要像素级预处理执行位置及其对应的数据传输路径，当前消融结果支持的是这条完整受测路径的效果，不能进一步分解为某一个 CUDA kernel 或某一次主机—设备传输的独立因果贡献。

## 4.3 Pinned内存的增量收益

在保持 CUDA 预处理语义、TensorRT Engine 和后处理过程不变的条件下，V3R 仅将 V2R 的 pageable host staging 替换为 pinned host staging。V3R 的平均帧率为127.097 FPS，对应5次独立运行 FPS 的样本标准差为1.279 FPS；其逐帧平均延迟为7.812 ms。

与 V2R 相比，V3R 的 FPS 提高4.0738%，平均延迟降低4.0349%。这一变化方向表明，在当前离线回放工作负载和数据路径下，锁页主机暂存能够在 V2R 已获得的主要收益基础上进一步改善平均性能，但其增量幅度小于 V0→V2R 的路径变化。

由于 V2R 和 V3R 的正式隔离变量为主机原始图像暂存的内存分配类型，上述结果可用于描述本文受测路径中 pageable 与 pinned staging 的平均性能差异。但该结果并不能推出 pinned memory 在其他模型、输入尺寸、设备或并发拓扑下均具有同等收益，也不能据此认为 V3R 实现了数据传输与推理的跨帧异步重叠。

## 4.4 尾延迟与适用范围讨论

V3R 在平均指标上表现出有限的正向增量，但尾延迟并未呈现一致方向。V2R 的 P95 和 P99 分别为9.827和11.529 ms，而 V3R 分别为9.842和11.515 ms。与 V2R 相比，V3R 的 P95 增加0.1514%，即数值略高；P99则降低0.1184%，即数值略低。两个百分位的变化方向相反，且变化幅度均较小，因此不能据此得出 pinned staging 能够一致降低尾延迟的结论。

这一结果也说明，平均性能和尾延迟应分别评价。V3R 相对于 V2R 同时获得了4.0738%的 FPS 增量和4.0349%的平均延迟降低，但这些平均指标的改善没有同步转化为 P95、P99 的一致下降。因此，就本文冻结工作负载而言，pinned staging 的主要作用应限定为平均性能上的小幅增量，而非稳定的尾延迟优化手段。

上述结论仅适用于本文实际测试条件，即单一 Jetson Orin Nano Super 平台、固定 YOLOv8n INT8 Engine、640×640输入、batch size为1以及180幅图像的离线文件回放。本文的性能结果采用5次独立进程和逐帧描述性统计，没有进行置信区间、假设检验或统计显著性推断；实验也未测量功耗、资源占用、长期耐久性或真实相机输入。因此，本文结果用于说明该冻结配置下的数据路径权衡，不扩展为对其他平台、模型或工业现场运行条件的普适性能结论。
