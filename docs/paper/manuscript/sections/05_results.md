# 4 结果与分析

## 4.1 正确性约束验证

任务行为保持是性能比较的准入条件。在冻结180幅测试图像和统一评价程序下，V2R通过预定义核验，V3R由同一评价器确定性重算；三条路径的汇总指标相同，类别级AP50与Recall最大差异均为0（表3）。该结果只确立冻结任务行为下的可比性，不表示逐位相等或未来输入上的普适等价。

**表3　三条路径在冻结工作负载和统一评价程序下的任务级正确性。**

| Path | Precision / Recall / mAP50 / mAP50-95 |
|---|---:|
| V0 | 0.6913 / 0.6991 / 0.6476 / 0.3523 |
| V2R | 0.6913 / 0.6991 / 0.6476 / 0.3523 |
| V3R | 0.6913 / 0.6991 / 0.6476 / 0.3523 |

## 4.2 路径级重构的E2E响应

V0和V2R的平均FPS分别为54.600和122.122，合并样本平均E2E延迟分别为18.273 ms和8.140 ms。由此，\(P_0\rightarrow P_2\)达到2.236671×原始FPS比，按论文精度为2.24×；平均延迟降低55.4519%，按论文精度为55.45%。整体结果见图2。

**图2　三条路径的端到端性能。(a) 为5个独立进程FPS的均值±样本标准差；(b)(c) 为每条路径合并5400个延迟样本的均值、P95和P99。**

该观测是\(R,F,M\)改变而\(E\)不变的耦合路径级E2E响应。式（2）的名义输入复制载荷由4.9152 MB/frame降至0.1200 MB/frame，形成40.96×结构对比，但该量不是实测带宽、流量或H2D时间。由于无阶段插桩及总线/DRAM流量测量，2.24×只能归属于完整\(P_0\rightarrow P_2\)路径，不能分解为GPU预处理、H2D、CUDA核函数或表示变化的贡献，也不表示40.96×传输加速。

## 4.3 暂存策略的增量响应

V3R平均FPS为127.097，平均E2E延迟为7.812 ms；相对V2R，FPS提高4.0738%（论文值+4.07%），平均延迟降低4.0349%（论文值−4.03%）。

该观测仅将额外打包原始图像的主机暂存由pageable改为pinned，\(R,F,E\)、GPU预处理语义、Engine、stream和下游结构均不变。其平均响应小于耦合路径级干预，但这仅描述受测系统内两种干预范围，不表示组件重要性，也不推出pinned内存在其他平台、模型或负载下具有普遍收益。

## 4.4 平均性能与尾延迟响应

5个独立进程中，V2R与V3R的进程级FPS范围分别为121.443–122.759和125.595–128.301，进程平均延迟范围分别为8.098–8.185 ms和7.740–7.894 ms，分布见图3。V3R相对V2R的合并样本P95变化为+0.1514%（论文值+0.15%），P99变化为−0.1184%（论文值−0.12%）。

**图3　运行级分布与尾延迟。各点为独立进程级描述量，横向偏移仅用于区分，不表示运行配对。**

进程级均值范围均不重叠，说明平均响应在5个独立进程中重复观察到，而非仅由单一异常进程形成；与此同时，P95与P99变化方向相反，未形成一致的尾延迟改善证据。两类观测共同表明，平均响应和尾延迟是不同评价维度，局部策略在本实验中改善均值并不意味着尾部指标同步改善。

不同路径的进程独立且不配对，本文不据此进行显著性推断；现有数据也不支持“pinned改善稳定性”的结论。

## 4.5 解释边界与局限性

在本文这类固定推理对象的数据路径评价中，受控结果支持一项有边界的工程原则：应先把耦合的路径级结构决策与局部暂存策略细化分开；只有在其余结构变量受控后，局部策略响应才具有清晰解释；完整E2E平均响应与尾部响应还应分别评价，不能相互替代。该原则用于组织本文同类受控评价，不构成普遍优化定律。

本文只评价单一Jetson平台、YOLOv8n TensorRT INT8混合精度Engine、NEU-DET固定180幅离线回放工作负载和单帧顺序拓扑，未覆盖真实相机、跨平台、跨模型或跨数据集泛化。运行状态只有非连续温度观察，没有连续遥测、功耗或能耗测量，也没有独立归档的频率证据。实验未测量阶段级H2D、预处理或CUDA核函数时间，也未测量实际总线或DRAM流量，因而不能进行组件级因果分配。每条路径5个独立进程仅支持描述性解释，不支持统计显著性推断。上述限制将结论约束为受测系统中的路径结构—E2E响应关系。
