# 4 结果与分析

## 4.1 正确性

三条路径在冻结180幅测试图像和统一评价程序下获得相同的汇总任务指标，类别级最大AP50与Recall路径间差异均为0，结果见表3。V3R由同一评价器对冻结预测结果确定性重算，并非新的推理或参数选择；该一致性不扩展为逐位相等或未来输入上的普适结论。

**表3　三条路径在冻结工作负载和统一评价程序下的任务级正确性。**

| Path | P / R / mAP50 / mAP50-95 |
|---|---:|
| V0 | 0.6913 / 0.6991 / 0.6476 / 0.3523 |
| V2R | 0.6913 / 0.6991 / 0.6476 / 0.3523 |
| V3R | 0.6913 / 0.6991 / 0.6476 / 0.3523 |

## 4.2 整体E2E性能

V2R相对V0达到2.24× FPS，平均延迟降低55.45%，构成完整输入形成路径重构的主要E2E平均性能增量。V3R相对V2R的FPS变化为+4.07%，平均延迟变化为−4.03%，表明pageable→pinned暂存只带来有限平均增量，整体结果见图3。

**图3　三条路径的端到端性能。(a) 为5个独立进程FPS的均值±样本标准差；(b)(c) 为每条路径合并5400个延迟样本的均值、P95和P99。**

## 4.3 数据路径分析

V0复制`1×3×640×640×4=4.9152 MB/frame`的FP32 NCHW输入，V2R/V3R复制`600×200=0.1200 MB/frame`的packed BGR输入，名义输入复制载荷比为40.96×。这是名义输入复制载荷，不是实测总线流量、带宽、H2D时间，也不能作为测得2.24× E2E结果的独立因果解释。

## 4.4 运行级分布与尾延迟

5个独立进程中，V2R与V3R的进程级FPS范围分别为121.443–122.759和125.595–128.301，进程平均延迟范围分别为8.098–8.185 ms和7.740–7.894 ms，分布见图4。两组范围在本次样本中不重叠，但不同路径的进程不配对，本文不据此进行显著性推断。

**图4　运行级分布与尾延迟。各点为独立进程级描述量，横向偏移仅用于区分，不表示运行配对。**

V3R相对V2R的合并样本P95变化为+0.15%，P99变化为−0.12%；两项变化均低于0.2%且方向相反，未形成一致的尾延迟改善证据。平均性能和尾部结果应分别解读。

## 4.5 相关工作定位

## 4.6 局限性

本文仅评价单一Jetson平台、YOLOv8n TensorRT INT8混合精度Engine、NEU-DET数据集和固定离线回放工作负载，未覆盖真实相机或跨平台/跨模型泛化；运行状态仅有非连续温度观察，没有连续遥测、功耗测量或独立归档的频率证据；实验也未测量阶段级H2D/预处理时间及实际总线或DRAM流量，因而40.96×名义载荷不能分配为单个组件的因果贡献。5次独立进程只支持描述性结果，不支持统计显著性推断。
