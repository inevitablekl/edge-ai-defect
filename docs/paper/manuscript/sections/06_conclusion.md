# 5 结论

固定推理对象不唯一决定输入数据路径。本文以\(P=(R,F,M,E)\)描述跨边界表示、输入张量形成位置、额外打包原始图像暂存策略和执行拓扑，以区分\(R,F,M\)变化而\(E\)不变的路径级重构与仅改变\(M\)的暂存策略细化；并将平均与尾部响应分别评价。

在冻结180幅测试图像且三条路径任务级评价一致的条件下，\(P_0\rightarrow P_2\)使FPS达到2.24×、平均E2E延迟降低55.45%；\(P_2\rightarrow P_3\)使FPS提高4.07%、平均延迟降低4.03%，而P95增加0.15%、P99降低0.12%，未形成一致的尾延迟改善证据。由此得到的受限工程认识是：固定推理对象的数据路径评价应先分离路径级结构决策与局部暂存策略，并在其他结构变量受控后评价局部策略，同时保留均值与尾部两个响应维度。

上述结论仅适用于本文单一Jetson平台、检测器/Engine、数据集、离线回放与单帧顺序配置，不作阶段级因果、统计显著性或跨平台/模型普适推断。
