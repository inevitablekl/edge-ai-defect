# 5 结论

本文以固定推理对象下的输入数据路径为研究对象，将跨边界表示、输入张量形成位置、额外打包原始图像暂存策略和执行拓扑作为结构变量。在冻结180幅测试图像且三条路径任务级评价一致的条件下，包含\(R,F,M\)变化且\(E\)保持不变的路径级\(P_0\rightarrow P_2\)使FPS达到2.24×、平均E2E延迟降低55.45%；仅改变\(M\)的局部\(P_2\rightarrow P_3\)使FPS提高4.07%、平均延迟降低4.03%，而P95增加0.15%、P99降低0.12%，未形成一致的尾延迟改善证据。

结果说明，包含表示、张量形成位置及相应暂存组织变化的路径级干预，与仅改变主机暂存策略的局部干预属于不同层级，其完整E2E响应不能由单个API或名义载荷直接解释。对于本文这类固定推理对象的数据路径评价，应区分跨边界表示、张量形成位置和主机暂存策略，并将平均性能与尾延迟作为独立响应维度。该认识仅适用于本文单一Jetson平台、检测器/Engine、数据集、离线回放与单帧顺序配置，不作阶段级因果、统计显著性或跨平台/跨模型普适推断。
