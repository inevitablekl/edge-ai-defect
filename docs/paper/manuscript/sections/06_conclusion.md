# 5 结论

本文重构了Jetson端YOLOv8n TensorRT INT8混合精度部署的输入形成与主机—设备数据路径。在冻结180幅测试图像上保持三条路径任务级评价一致时，V2R相对V0达到2.24× FPS、平均延迟降低55.45%，表明完整输入形成路径重构构成受测配置中的主要E2E平均性能增量。

V3R相对V2R的FPS变化为+4.07%、平均延迟变化为−4.03%，只体现固定实现中的有限平均增量；P95为+0.15%、P99为−0.12%，两项均低于0.2%且方向相反，未形成一致的尾延迟改善证据。结论限于本文单一平台、检测器/Engine、数据集和离线回放工作负载，不作组件级因果或普适收益推断。
