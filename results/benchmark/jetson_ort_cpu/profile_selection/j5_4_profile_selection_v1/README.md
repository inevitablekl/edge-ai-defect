# Stage J J5.4 Profile Selection v1

Status: PASS. Controlled profile: k1. Tuned profile: k5.

This selection was performed by read-only analysis of the published J5.3 Candidate Sizing Evidence. No application or benchmark rerun was performed, and no candidate was added or removed.

Controlled k1 is frozen for minimum resource use, lower observed temperature/power, deterministic output, and reproducibility. Tuned k5 is frozen because it provides a large latency reduction while k6 provides only a 3.48% further cycle-mean reduction at higher total CPU utilization, memory, temperature, and VDD_IN cost.

The evidence contains no images, hostname, IP address, credentials, or user paths. This is profile selection evidence, not a formal performance baseline.
