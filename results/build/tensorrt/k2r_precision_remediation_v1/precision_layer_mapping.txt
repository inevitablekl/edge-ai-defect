TensorRT 10.3 CLI semantics observed in the frozen help:
  precisionConstraints=obey means meet layerPrecisions/layerOutputTypes or fail.
  layerPrecisions is comma-separated layerName:precision; no wildcard is used.
  layerOutputTypes is comma-separated layerName:type; multi-output types use +.
  The actual policy names contain slash and dot characters only; the complete
  CLI value is shell-quoted as one argument. The help documents escaped
  single-quote wrapping for input names, but no layer-name-specific quoting
  beyond the exact grammar; no layer policy name requires such quoting.

The mapping is based on actual TensorRT parser registration, input/output
tensors and shapes, not substring guesses. The full machine-readable mapping
is precision_layer_mapping.json.
